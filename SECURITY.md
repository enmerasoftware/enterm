# Security

Enterm runs programs in your terminal, relays approvals and can pair with a phone, so a security bug matters.

Please do not open a public issue for a vulnerability. Use GitHub's private reporting instead: **Security → Report a vulnerability** on [github.com/enmerasoftware/enterm](https://github.com/enmerasoftware/enterm/security/advisories/new).

Include what an attacker can do, the steps to reproduce it and the Enterm version. You will get an answer, and credit in the release notes if you want it.

Fixes go into the latest release only; Enterm updates itself through Sparkle.
