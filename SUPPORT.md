# Getting help

## Read first

- [FAQ](docs/faq.md): common questions about what Enterm does and does not do.
- [Troubleshooting](docs/troubleshooting.md): fixes for the problems people run into most.
- [README](README.md): installing, the main features and the phone app.

## Ask a question

Ask in [GitHub Discussions](https://github.com/enmerasoftware/enterm/discussions), in the **Q&A** category.
English and Turkish are both fine. Discussions are the right place for "how do I...", setup help, ideas
that are not ready for an issue, and sharing how you use Enterm.

Please do not open an issue for a question; issues are for bugs and concrete feature requests.

## What to include

The more of this a question has, the faster it gets a useful answer:

- The Enterm version (Settings → About) and how you installed it (DMG, Homebrew or from source).
- The macOS version and your Mac's model and chip.
- The program in the session (Claude Code, Codex, Gemini, ...) and its version.
- Whether the iPhone app is involved, and if so the iOS version and whether you use the default relay or
  your own.
- What you did, what you expected and what happened instead.
- Screenshots or terminal output, with tokens, keys and private paths removed.

## Report a bug or request a feature

Use the [issue forms](https://github.com/enmerasoftware/enterm/issues/new/choose). Search the existing issues
first.

## Security problems

Never in public. Follow the [security policy](SECURITY.md) and report privately through GitHub.

## Problems with the agent programs

Enterm runs Claude Code, Codex and the other programs exactly as they ship. If a problem also happens when
you run the program in a plain terminal, its vendor is the right place to report it.
