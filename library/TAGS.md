# Tags

Every item carries one to four tags from this list, so Enterm's Library page can filter by them. `scripts/build-index.mjs` reads the table below; a tag that is not here fails the check.

Want a new tag? Open a pull request that adds a row here and uses it on at least three items.

| Tag | Use it for |
|---|---|
| `review` | Reading code or a change and reporting what is wrong |
| `testing` | Writing, fixing or speeding up tests |
| `refactor` | Changing structure without changing behaviour |
| `debugging` | Finding and fixing the cause of a failure |
| `docs` | READMEs, onboarding notes, changelogs, PR descriptions, comments |
| `security` | Secrets, input validation, auth, dependency audits |
| `performance` | Profiling, slow paths, queries, memory |
| `design` | How an interface looks and reads |
| `frontend` | Web and desktop user interfaces |
| `backend` | Servers, APIs, jobs, services |
| `mobile` | iOS, Android and cross-platform apps |
| `git` | Branches, commits, pull requests, history |
| `onboarding` | Getting to know a codebase |
| `data` | Databases, migrations, schemas, data files |
| `accessibility` | Screen readers, keyboard use, contrast, text size |
| `i18n` | Translations, locales, formatting of dates, numbers and money |
| `dependencies` | Adding, upgrading and auditing packages |
| `ci` | Continuous integration and build pipelines |
| `observability` | Logging, metrics, tracing, error reporting |
| `image` | Icons, screenshots and image files |
| `video` | Video and audio files |
