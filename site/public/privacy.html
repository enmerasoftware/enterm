Privacy

Privacy

Short version: this site has no trackers, and the services behind Enterm keep as little as they can.

This website

No analytics, no ads, no tracking cookies and no third-party scripts. Your language choice is kept in your browser's local storage. The page asks GitHub's public API for the star count and the latest version, reads the reviewed Library from GitHub, and loads fonts from Google Fonts; those services see the request as they would for any visit.

The Library server

When you share, like or report a Library entry from the Enterm app, the server stores what you submitted (the entry's text and the name you give), a salted one-way hash of your IP address and a salted one-way hash of a random id created for each Enterm install. The hashes are used only for rate limits, for counting one like per install and for handling reports. Nothing else is stored, and the hashes cannot be turned back into your IP address or install id. Shared entries are public.

The phone relay

Once you pair an iPhone, the Mac and the phone talk through a relay. It only carries end-to-end encrypted bytes that it cannot read, and it keeps no logs. You can also run your own relay.

The app

Enterm has no telemetry. It goes online only for things you can see: update checks, the dictation model or an agent's installer when you ask, web pages you open, the Library, and the relay once a phone is paired. Your agents talk to their own vendors exactly as in a plain terminal, and your subscription tokens never reach Enterm. Details are in the README.

Questions

Ask in GitHub issues. To report a vulnerability privately, follow the security policy.
